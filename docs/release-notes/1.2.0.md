## Veloce PQC SDK 1.2.0

**Click-to-run Windows packages.** The Windows release is now a signed-ready,
branded deliverable: `Veloce.exe`, the Start Menu shortcut, and the Apps and
features entry carry the Veloce icon; the WiX v5 MSI shows the license and
install-directory dialogs with Lightrider artwork and offers to launch the
app when installation completes. `SHA256SUMS-windows-x86_64.txt` verifies
the downloads. The `Release` workflow builds the packages and attaches them
to a GitHub Release. End users do not build anything: see the Windows quick
start below.

**Entropy seed source: CPU RDSEED.** The FIPS DRBG is now seeded directly
from the processor's SP 800-90B entropy source (RDSEED) through the
Lightrider seed callback, with SP 800-90B health tests at H = 8 bits per
sample (RCT cutoff 4, APT 13 of 512, 1024-sample startup test), fail-closed.
The previous source, operating system DRBG output (`getrandom`,
`BCryptGenRandom`), formed an SP 800-90C RBGC chain from an RBG that is not
validated on generic operating environments; it remains available only by
explicit configuration (`entropy.source: os-drbg`) and is reported as an
unvalidated chain with no security-strength claim. Status fields now state
`source_kind`, `rbg_construction`, and `security_strength_claim`; the former
`verified_local` flag is gone. No ESV certificate is claimed for any source.

**Desktop interface redesign.** Light appearance by default following the
system dark setting, system type stack, one type scale with sentence-case
labels, neutral surfaces, and the Lightrider gradient (yellow, amber,
orange, red, crimson) as the accent. Behavior and the local API are
unchanged; the page gained `/favicon.svg`.

**Validation posture unchanged.** Certificate #4718 lists no Windows or
macOS operating environment. wolfSSL has completed testing of the
Windows 11 Pro OE; publication is pending, so Windows carries
`pending_publication` and no validated-deployment claim. Discovery-only
packages contain no cryptographic module.

Gate battery: all tests green on the Linux x86-64 reference machine
(`bash scripts/run_gates.sh`). Windows artifacts are statically tested
(`tests/test_windows_artifacts.py`); native execution of the Windows FIPS
runtime is an open item.

## Downloads

| Platform | File | Contents |
|---|---|---|
| Linux x86-64 | `veloce-1.2.0-linux-x86_64.tar.gz` | Full runtime: Veloce agent, CLI, qSearch, wolfCrypt FIPS module (object code) and PQC provider with recorded hashes, launcher, docs. Extract and run `bin/veloce-fire-up`. |
| Windows 10/11 x86-64 | `veloce-1.2.0-windows-x86_64.msi`, `.zip` | Veloce Desktop, discovery-only (qSearch and UI; no cryptographic module). Quick start below. |
| macOS arm64 | `veloce-1.2.0-macos-arm64.dmg` | Veloce Desktop, discovery-only. Ad-hoc signed: Gatekeeper blocks the first launch; allow it under System Settings, Privacy & Security, `Open Anyway` (macOS quick start below). |
| Any | `veloce_pqc-1.2.0-py3-none-any.whl` | Pure-Python SDK; requires a reachable agent (Linux). |
| Source | `veloce-1.2.0-source.tar.gz` | Lightrider-owned source snapshot; contains no wolfSSL source. |

Verify: `sha256sum -c SHA256SUMS-linux-x86_64.txt` (Linux),
`sha256sum -c SHA256SUMS-windows-x86_64.txt` (Windows),
`shasum -a 256 -c SHA256SUMS-macos-arm64.txt` (macOS).
