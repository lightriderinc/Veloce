Cloud entropy mix-in

              off
            

            
When enabled, the agent fetches signed entropy packets from the Lightrider EMS and mixes them into the DRBG as additional input. This adds zero credited entropy: the local verified provider stays the only seed and the FIPS claim is unchanged. If EMS is unreachable, mixing is skipped and local operation continues.
