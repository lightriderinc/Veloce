How it works
In three steps

            
    
              
  1. Collect. The processor's built-in noise source produces random bits. Nothing is read from the internet or the operating system.
    2. 
              
  2. Check. Each block passes repetition and proportion tests. A failure stops key generation until the source recovers.
    3. 
              
  3. Generate. The FIPS 140-3 validated generator turns checked bits into keys and signatures. Raw random bits are never shown or exported.
